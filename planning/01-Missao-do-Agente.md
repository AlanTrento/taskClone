
# Missão do Agente

Construir um clone visual do Google Tasks Desktop utilizando React + Typescript + Ant Design.

## Obrigatório
- Aplicar a skill clean-ddd.

- UI semelhante ao Google Tasks.

Presentation
→ Hook
→ ViewModel
→ UseCase
→ Repository

→ Mock
